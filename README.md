# Outdoor Gym

Find free outdoor gyms and calisthenics parks near you, see them on a map, and tap to navigate there in Google Maps. Has quick shortcuts for Valencia (Spain) and Seattle.

## Install

On an Android phone, open this link in Chrome and install the file it downloads:
https://github.com/wurp/outdoor-gym/releases/download/test-build/app.apk

## Keep building

In the Claude app, open **Code** → **New session**, choose `outdoor-gym` above the message box, and describe what to change. (On a computer, [this link](https://claude.ai/code?repositories=wurp/outdoor-gym) opens it directly.)

Gym locations come from [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors.

Built with [vibe-dev-template](https://github.com/wurp/vibe-dev-template) and Claude.
